# 🍕 Padre Gino's Pizza App - Complete Ordering Solution

## Overview

The "Padre Gino's Pizza App" is a full-stack pizza ordering application designed to provide users with a seamless experience when ordering their favorite pizzas. Built with **React** for the frontend and **Express** for the backend, this application combines modern web technologies to offer an efficient and enjoyable pizza ordering service.

-----

## Features ✨

  * **User-Friendly Interface**: Easily navigate the app with a clean and intuitive design.
  * **Real-Time Ordering**: Place orders and see updates in real-time.
  * **Pizza Customization**: Choose from a variety of toppings and sizes.
  * **Order History**: View past orders for easy re-ordering.
  * **Responsive Design**: Works well on both desktop and mobile devices.

-----

## Technologies Used 🛠️

This project leverages a variety of technologies to deliver a robust solution:

### Frontend

  * **React**: A JavaScript library for building user interfaces.
  * **Context API**: For state management.
  * **React Query**: For data fetching, caching, and synchronization.
  * **Vite**: A fast build tool for modern web projects.
  * **TanStack Router**: For routing in the frontend.

### Backend

  * **Node.js**: A JavaScript runtime environment.
  * **Express**: A web application framework for Node.js.
  * **SQLite**: A lightweight, file-based database.

### Deployment

  * **Vercel**: For frontend deployment (based on the provided link).

## Getting Started 🚀

To set up the project locally, follow these steps:

1.  **Clone the Repository**:

    ```bash
    git clone https://github.com/mrsMatheusRocha/Padre-Ginos.git
    cd Padre-Ginos
    ```

2.  **Install Dependencies**: Navigate into both the `client` (frontend) and `server` (backend) directories to install the necessary packages.

    For the frontend:

    ```bash
    cd client
    npm install
    ```

    For the backend:

    ```bash
    cd server
    npm install
    ```

3.  **Set Up the Database**: The application uses SQLite. Ensure you create the database file as specified in the backend configuration (if necessary).

4.  **Run the Application**:

    Start the backend server:

    ```bash
    cd server
    npm start
    ```

    In a new terminal window, start the frontend development server:

    ```bash
    cd client
    npm start
    ```

5.  **Access the Application**: Open your browser and go to `http://localhost:3000` to see the application in action.

-----

## Usage 👨‍💻

Once the application is set up, you can start ordering pizzas right away:

  * **Order Pizza**: Browse the menu, customize your pizza, and place an order.
  * **Check Order Status**: View the real-time status of your order.
  * **Check Past Orders**: View the last orders to know your queue position.
